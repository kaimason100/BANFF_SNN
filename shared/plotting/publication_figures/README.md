# Publication figure scripts

This folder contains the self-contained CPU plotting scripts required for the
manuscript figures. They are intentionally kept outside the simulation
backend so they can be edited without changing training or testing code.

Editable Live Editor scripts:

- `analyse_jitter.mlx` (creates timestamped rate-preserving within-window timing-shuffle analysis data)
- `plot_jitter.mlx` (loads the newest saved timing-shuffle analysis and renders the publication figure)
- `plot_full_rank_publication_figure.mlx` (full-rank sparse-connectivity, Van der Pol, firing-rate, and active-fraction panels)
- `plot_spsa_publication_figure.mlx` (SPSA bias-update schematic, Van der Pol, firing-rate, and active-fraction panels)
- `plot_flowchart_publication_figure.mlx` (manuscript layout: A learning flowchart, B network plus legend, C ALIF dynamics)
- `plot_neural_activity_publication_panels.mlx`
- `plot_phase_portraits_return_maps_poincare_sections.mlx`
- `plot_dynamics_ic_variation_publication.mlx`
- `plot_lorenz_neuron_count_publication.mlx`

Current alignment notes:

- Figure creation avoids MATLAB `Name` fields.
- The timing-shuffle analysis uses 25, 50, 100, 200, 400, and 800 ms windows.
  Warmup spikes are replayed unchanged. Beginning exactly at the first scored
  timestep, the analysis independently redistributes each neuron's spikes
  without replacement inside non-overlapping windows, preserving that neuron's
  count in every scored-interval window. No shuffle window crosses the warmup
  boundary. Spike-event export stores a CPU unperturbed output and a matched
  true continuation initialised from that same CPU rollout's terminal warmup
  state. The analysis reconstructs the unshuffled CPU events, hard-checks that
  output against the saved CPU baseline, and uses only this single-backend
  baseline/truth pair for every shuffled condition. Old event files lacking
  these fields are rejected and must be regenerated by the dynamics tests.
